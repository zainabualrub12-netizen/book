# Book Management System

A software application developed in C# to manage, catalog, and track books. This repository demonstrates solid fundamental software engineering skills, focusing on backend operations, data manipulation, and structured desktop/web component logic.

## 🚀 Key Features
* **Book Cataloging:** Efficiently add, view, and organize book records.
* **Search & Filter:** Search functionality to look up books by title, author, or genre.
* **Data Management:** Implements secure handling of information logic for consistent application states.

## 🛠️ Tech Stack
* **Language:** C#
* **Framework:** .NET Framework / .NET Core
* **IDE:** Microsoft Visual Studio 2022

## 📋 Software Engineering Practices Applied
* **Object-Oriented Programming (OOP):** Applied clean class structures to represent system entities.
* **Component Decoupling:** Maintained a clean layout ensuring components communicate predictably.
